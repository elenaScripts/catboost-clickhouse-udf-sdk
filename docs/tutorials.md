# Tutorials

Choose a tutorial based on what you want to run:

- [Build your first UDF bundle](quickstart.md). Train a synthetic classifier and create a ZIP without a ClickHouse server.
- [Run the local demo](local-demo.md). Start a local server, deploy the demo UDF, load logs, and compare SQL scores with direct CatBoost predictions.
- [Score log events from a file](filelog-demo.md). Read synthetic JSON logs with FileLog and score them using the local UDF.
- [Run the synthetic incident scenario](synthetic-scenario.md). Train and test on separate simulated time periods, then compare thresholds and incident windows.

Each tutorial uses generated data. None establishes how a model performs on real incidents.
